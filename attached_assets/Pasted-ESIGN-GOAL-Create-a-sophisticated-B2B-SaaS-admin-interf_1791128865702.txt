ESIGN GOAL

Create a sophisticated B2B SaaS admin interface that feels like a mature sales-intelligence, CRM, operations, or workflow platform.

The interface should feel:
- Dense but highly organized
- Professional rather than decorative
- Fast and operational
- Data-first
- Modern enterprise SaaS
- Suitable for users spending several hours per day inside the application

Think Apollo / Linear / Attio / modern CRM admin tooling.

The primary desktop experience should be optimized for 1440px–1920px screens while remaining responsive.

--------------------------------------------------
27. UX PRINCIPLES
--------------------------------------------------

Follow these principles throughout the build:

1. DATA FIRST
The table is the dominant element.

2. HIGH INFORMATION DENSITY
Users should see substantial information without excessive scrolling.

3. QUIET CHROME
Navigation and controls should not compete with the data.

4. CLEAR HIERARCHY
Page title → tabs → system state → controls → data.

5. PROGRESSIVE DISCLOSURE
Advanced actions belong inside menus, dropdowns, and contextual panels.

6. CONSISTENCY
Buttons, dropdowns, filters, menus and tables should behave consistently throughout the application.

7. PROFESSIONAL OVER PLAYFUL
Avoid gradients, glassmorphism, excessive shadows, huge rounded cards, oversized icons, or consumer-app styling.

--------------------------------------------------
28. VISUAL DETAILS TO AVOID
--------------------------------------------------

DO NOT:

- Use giant cards
- Put the entire table inside a rounded floating card
- Use excessive border radius
- Use gradients
- Use glassmorphism
- Use excessive shadows
- Use huge typography
- Add decorative illustrations
- Make every control a pill
- Create excessive whitespace
- Use bright accent colors everywhere
- Make the page resemble a marketing dashboard

This should look like an application built for serious daily operational work.
