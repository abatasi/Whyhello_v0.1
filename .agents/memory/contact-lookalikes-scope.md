---
name: Contact Lookalikes scope
description: User-defined scope for finding similar contacts.
---

Contact Lookalikes finds similar contacts already in the app, not new people from external sources.

**Why:** The user explicitly selected “Contacts already in the app” when asked which pool Lookalikes should search.

**How to apply:** Keep this flow within the existing contact repository. External discovery or importing new leads requires a separate user request.
