---
name: Dark card surfaces
description: Visual rule for dark-mode panels in the Contact Database.
---

In dark mode, boxes, cards, and panels should use the theme's default background rather than colored or lighter fills. Use visible neutral or category-colored borders to distinguish surfaces.

**Why:** The user wants dark mode itself to provide the fill; colored card backgrounds make the interface less consistent and can reduce text contrast.

**How to apply:** For new card-like surfaces, suppress decorative gradients in dark mode and use the theme background with a clear border. Keep semantic fills for avatars, buttons, badges, status markers, selection/hover feedback, and images. Preserve the separate light-mode treatment.
